# Design: a total in the Usage popover and window

## D1. Two lines and their sum

Below the list, after a divider: "Headquarter" (app and host), "All sessions" (every running
session's agent, children and shell panel, the same figures the rows show) and "Total" in
semibold, each with CPU (100 % = one core) and memory. While the first sample is being taken, the
CPU figures read "…" as the rows do. The popover's total counts every running session, not only
the five it lists, and says so ("All 12 sessions").

Rejected: one total line only (the owner chose to see Headquarter apart from the sessions).
